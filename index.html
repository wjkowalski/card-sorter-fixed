Card Sort Builder

This repo is public. Anyone can download it, use it, and modify it as they wish!

INSTRUCTIONS:
Add cards with the large plus button, then drag them into categories or subcategories.
To send someone a list of unsorted cards so they can sort them, use Share Link:

  1. Enter the card names individually in the Create Cards section
  2. Click Generate Share Link
  3. Click Copy Share Link
  4. Sharing that link with anyone should bring them to the sorting tool with the unsorted cards pre-populated and ready to be sorted
To complete the APPD 5012 Card Sorting assignment, or to simply send someone your list of sorted cards as an unsortable object, use Export Data:
  1. Complete the card sorting activity.
  2. Click the Export Data button.
  3. Click the Copy Export button. This will put a JSON object on your clipboard.
  4. Paste the export into a text file, and send that text file to the person you want to share it with. They will then click Open Interpreter and paste the JSON into the interpreter field to see the results.
